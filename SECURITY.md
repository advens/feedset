# Security Policy

## Reporting a vulnerability

Report privately:

- GitHub: Security, Report a vulnerability (private advisory) on this
  repository, or
- email jeremie.jourdin@advens.fr.

Do not open a public issue for a bug that reveals `MISP_KEY`, a
MaxMind license, or the contents of `enrich.json`.

Include the commit, the command line with the secrets redacted, and
what was written or published.

## What to expect

- Acknowledgement within 3 business days.
- An initial assessment and a target fix window within 10 business days.
- Coordinated disclosure, normally within 90 days, with credit unless
  you ask otherwise.

## Supported versions

The current `main` commit. This repository has no release tag yet.
A tag, when it exists, is `N.N.N` with no `v` prefix.
